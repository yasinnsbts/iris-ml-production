# Model Card: Iris Classifier

## 1. Общая информация

**Название модели:** Iris Classifier  
**Версия проекта:** 0.1.0  
**Тип задачи:** многоклассовая классификация  
**Алгоритм:** Logistic Regression  
**Библиотека:** scikit-learn  

Модель определяет вид цветка Iris по четырём числовым характеристикам растения.

Поддерживаются три класса:

- Iris setosa;
- Iris versicolor;
- Iris virginica.

Проект является учебным примером разработки и production-like оформления ML-модели.

## 2. Назначение модели

Модель предназначена для автоматической классификации экземпляра Iris на основании измерений чашелистика и лепестка.

Основная задача модели — преобразовать набор числовых характеристик цветка в один из трёх классов Iris.

В рамках проекта модель используется для демонстрации основных этапов жизненного цикла ML-системы:

1. получение данных;
2. подготовка признаков;
3. обучение модели;
4. оценка качества;
5. сохранение обученной модели;
6. использование модели для предсказания;
7. автоматическое тестирование и контроль качества кода.

## 3. Предполагаемое использование

Модель может использоваться:

- для демонстрации задачи многоклассовой классификации;
- для учебных экспериментов с машинным обучением;
- для демонстрации организации production-like ML-проекта;
- как компонент учебного приложения классификации объектов Iris.

Модель не предназначена для принятия критически важных решений.

## 4. Использование вне предполагаемого назначения

Модель не следует использовать:

- для классификации растений других родов и видов;
- для работы с признаками, отличающимися от использованных при обучении;
- в научных или производственных процессах без дополнительной валидации;
- в задачах, где ошибка классификации может привести к значимым последствиям;
- как классификатор фотографий или текстовых описаний растений.

Модель принимает числовые измерения, а не изображения.

## 5. Входные данные

На вход модели поступают четыре числовых признака:

| № | Признак | Описание |
|---|---|---|
| 1 | Sepal length | Длина чашелистика |
| 2 | Sepal width | Ширина чашелистика |
| 3 | Petal length | Длина лепестка |
| 4 | Petal width | Ширина лепестка |

Каждый объект должен содержать ровно четыре признака.

Пример входных данных:

`[5.1, 3.5, 1.4, 0.2]`

## 6. Выходные данные

Результатом работы модели является один из трёх классов:

| Код класса | Вид |
|---|---|
| 0 | setosa |
| 1 | versicolor |
| 2 | virginica |

Функция `predict_species()` преобразует числовой класс в название вида.

Пример результата:

`setosa`

## 7. Данные для обучения

Используется классический набор данных Iris, доступный через `sklearn.datasets.load_iris`.

Набор содержит:

- 150 объектов;
- 4 числовых признака;
- 3 целевых класса;
- по 50 объектов каждого класса.

Данные разделяются на обучающую и тестовую выборки:

- 80% — обучение;
- 20% — тестирование.

Для воспроизводимости используется:

`random_state = 42`

При разделении применяется стратификация по целевому классу:

`stratify = y`

## 8. Архитектура и обучение модели

Модель реализована в виде `sklearn.pipeline.Pipeline`.

Pipeline содержит два последовательных этапа:

1. `StandardScaler` — стандартизация входных признаков;
2. `LogisticRegression` — многоклассовая классификация.

Конфигурация классификатора:

`LogisticRegression(max_iter=200)`

Последовательность обработки данных:

`Входные данные → StandardScaler → LogisticRegression → Предсказанный класс`

Использование Pipeline позволяет гарантировать, что одинаковая обработка признаков применяется как при обучении, так и при дальнейшем использовании модели.

## 9. Метрики качества

Основная метрика проекта — **Accuracy**.

На тестовой выборке текущая версия модели показывает:

**Accuracy = 0.933**

Это означает, что модель корректно классифицировала приблизительно 93.3% объектов тестовой выборки при текущем разбиении данных.

Метрика рассчитана на отложенной тестовой выборке размером 20% исходного датасета.

Для текущей версии проекта дополнительные метрики, такие как Precision, Recall и F1-score, не рассчитываются.

## 10. Ограничения модели

Основные ограничения модели:

- датасет содержит только 150 объектов;
- модель обучена только на трёх видах Iris;
- используются только четыре заранее определённых числовых признака;
- качество оценено на небольшой тестовой выборке;
- модель не проверялась на данных из других источников;
- модель не выполняет проверку реалистичности входных значений;
- текущий интерфейс не отображает вероятность или степень уверенности прогноза;
- качество модели на наборе Iris нельзя автоматически переносить на другие задачи классификации;
- модель не предназначена для работы с изображениями растений.

Высокое значение Accuracy в этом проекте объясняется в том числе относительной простотой и хорошей разделимостью классов набора Iris.

## 11. Почему используется машинное обучение

Класс объекта определяется комбинацией нескольких признаков, поэтому задача естественным образом формулируется как задача многоклассовой классификации.

Машинное обучение позволяет определить границы между классами на основе размеченных примеров вместо ручного задания большого количества правил и пороговых значений.

Для набора данных Iris задача достаточно проста и могла бы быть решена также эвристическими правилами. В данном проекте использование ML прежде всего демонстрирует универсальный data-driven подход и полный процесс разработки ML-модели.

## 12. Этические аспекты

Модель не работает с персональными данными и не принимает решения в отношении людей.

Основные риски связаны не с социальной дискриминацией, а с неправильным использованием модели за пределами её предполагаемого назначения.

Результат модели не следует интерпретировать как экспертное ботаническое заключение.

## 13. Техническая реализация

Основные компоненты проекта:

- `iris_classifier/data.py` — получение данных;
- `iris_classifier/train.py` — обучение, оценка качества и сохранение модели;
- `iris_classifier/predict.py` — загрузка модели и выполнение предсказания;
- `models/iris_model.joblib` — обученная модель, создаваемая локально;
- `tests/` — автоматические тесты.

Для управления зависимостями используется Poetry.

Для контроля качества проекта используются:

- Ruff;
- pytest;
- pre-commit.

## 14. Воспроизводимость

Обучение модели:

`poetry run python -m iris_classifier.train`

Запуск предсказания:

`poetry run python -m iris_classifier.predict`

Запуск тестов:

`poetry run python -m pytest -q`

Зависимости проекта описаны в `pyproject.toml`, а их разрешённые версии фиксируются в `poetry.lock`.
